# Local TTS Studio — Release v3.4.0 📂

Quality-of-life improvements for working with many projects and pasted documents.

## ✨ New Features

### 🏷️ Auto-title from the document
- When you **Parse** pasted Markdown, the project is now named after the document's **first line** (its title) — Markdown markers stripped. No more "Untitled Project" to rename by hand.

### 📜 Scrollable, cleaner project list
- The **Open Project** list no longer runs off the top and bottom of the screen when you have lots of projects — it now scrolls within the window.
- Each entry is simplified to just the **project title** plus **Open** and **Delete** buttons.

## 🐛 Fixes

- The metadata filter now also drops `Scriptures used:` lines (previously only the exact label `Scriptures:` was removed), so document headers like `**Scriptures used:** …` are no longer read aloud.

## 📥 Installation

1. Download `Local.TTS.Studio.v3.4.0.zip` from the **Assets** section below.
2. Unzip the file.
3. Drag the extracted `Local TTS Studio.app` into your `/Applications` folder.
4. Open the application. *(On first launch you may need to right-click → "Open" to bypass macOS Gatekeeper.)*

Existing users will be offered this update automatically via the in-app updater.
